# ptaszynski-pl-deploy

Gotowe pliki strony startowej ptaszynski.pl. Nie edytuj ich tutaj — źródła i skrypt wdrożenia są w repozytorium `ptaszynski-pl`.

cPanel → Git Version Control → ptaszynski-pl-deploy → „Update from Remote”, potem „Deploy HEAD Commit” (`.cpanel.yml` kopiuje pliki do `public_html/ptaszynski`).
